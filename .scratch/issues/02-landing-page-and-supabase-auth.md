# 02: Bento Grid OLED Landing Page and Supabase Authentication

**What to build:** A high-polish marketing landing page adhering to the late-2026 mobile-ui-craft aesthetic (Bento Grid layout, OLED obsidian #08090D theme, neon telemetry glow, model pricing comparison cards) seamlessly wired to Supabase Auth for visitor registration and login, with automatic profile initialization and redirection to the authenticated dashboard.

**Blocked by:** 01: Scaffold Next.js 15, Supabase Schema and Vercel Configuration.

**Status:** completed

- [x] High-polish landing page displaying live supported models (Claude 3.5 Sonnet, GPT-4o, DeepSeek-V3, Gemini 2.0 Flash) with transparent VND pricing.
- [x] Bento Grid design showcasing features: 3-second instant VietQR top-up, high-speed OpenAI-compatible reverse proxy, and multi-key management.
- [x] Responsive navigation header with quick login/register modal and account status pill.
- [x] Fully functional authentication flow using Supabase Auth (email/password sign-in and sign-up).
- [x] Automated user profile trigger ensuring new accounts start with a default profile row and zero credit.
- [x] Seamless redirect to the authenticated dashboard upon successful session establishment.
