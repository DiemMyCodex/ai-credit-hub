# Architecture and Tech Stack: Next.js 15 and Supabase

We chose Next.js 15 (App Router, TypeScript, Tailwind CSS) paired with Supabase (PostgreSQL, Auth, and Row Level Security) as the primary platform stack. Next.js provides server-side rendering for marketing/landing pages and serverless API route handlers for the proxy, while Supabase eliminates custom auth boilerplate and guarantees cryptographically enforced row-level access control over sensitive customer API keys and credit balances.
